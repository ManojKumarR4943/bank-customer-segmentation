# Bank Customer Segmentation using PCA and Weighted KNN

## Objective
This project classifies bank customers into profitability segments using machine learning techniques based on customer financial information.

---

## Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn

---

## Machine Learning Techniques
- PCA (Principal Component Analysis)
- Weighted KNN (K-Nearest Neighbors)

---

## Dataset
Bank Churn Dataset containing customer banking information such as:

- Credit Score
- Age
- Balance
- Number of Products

---

## Features Used
- CreditScore
- Age
- Balance
- NumOfProducts

---

## Target Variable
Segment (0–4)

Customer segments are created based on account balance distribution.

---

## Steps Performed
1. Data preprocessing
2. Feature selection
3. Customer segmentation using qcut
4. Train-test split
5. Feature scaling using StandardScaler
6. PCA dimensionality reduction
7. Weighted KNN model training
8. Model evaluation
9. Data visualization

---

## Visualizations
- Accuracy Graph
- Confusion Matrix
- PCA Scatter Plot
- Customer Segment Distribution Graph

---

## Output
The model generates:
- Accuracy Score
- Confusion Matrix
- Classification Report

---

## Conclusion
The machine learning model successfully segmented bank customers using financial attributes such as balance, age, credit score, and product usage. PCA and Weighted KNN improved customer classification and visualization performance.
